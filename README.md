# ui-taste-skill

面向网页、桌面软件、移动 App 和 Web 工作台的设计工作流。以出众美感、优美秩序、精致质感与产品自身气质为目标：可用和整齐只是底线。通过内容驱动的方向探索、构图与排印、材料样片、连续交互和正向审美验收，帮助模型做出完整而有吸引力的界面；为易漂移或不能读图的实现者提供明确的视觉执行包。不是固定皮肤，也不承诺所有模型必然产出优秀作品；跨模型效果仍需受控实验。

入口是 [SKILL.md](SKILL.md)。新设计读 [生成方法](references/generation.md)，参考适配读 [视觉校准](references/visual-calibration.md)，需要视觉依据时看 [示范拆解](references/visual-examples.md)；维护者使用 [效果验证](references/evaluation.md) 分开检查文档、功能、视觉和用户偏好。

- [字间方向工作室](assets/variant-board.html)：用同一份字体标本内容探索展陈与仪器两种完整方向，学习构图、对象尺度与操作关系的变化，而非只换配色。
- [索引工作台](assets/reference-workbench.html)：冷白工作面、深色导航、对象列表与详情，支持搜索、类型筛选、收藏及窄屏返回。
- [间阅读刊物](assets/reference-editorial.html)：中文排印、原创几何习作与疏密节奏，支持文章、主题筛选、收藏和返回。
- 这些示范均为原创虚构教学内容，不是审美上限、第三方成熟产品、用户已认可方案或跨模型生成实验。
- [软件关系精修实验室](assets/app-craft-lab.html)：自包含离线 HTML，比较同内容的排布关系，检查列表、详情、收藏与偏好。它是教学示例，不是原生 App 或默认模板。
- [项目雷达交互原型](examples/project-radar/index.html)、[案例说明](examples/project-radar/README.md)：保留原网页实验，不替换原报告站。用户认可旧稿的范围见视觉校准，不等于后续版本已获认可。
- [2.2 验证记录](docs/validation-2.2.md)、[2.1 验证记录](docs/validation-2.1.md)、[2.0 验证记录](docs/validation.md)：按版本查看已检查与未检查事项。[早期设计决定](docs/design.md) 保留历史背景。

不要把另一台机器的链接状态当成本机安装事实。2026-10-28 更名为 `ui-taste-skill` 后，`/Users/guoran/.qoder/skills/ui-taste-skill` 是指向 `/Users/guoran/Desktop/项目开发/ui-taste-skill` 的符号链接，修改源文件即可通过此入口读取；旧名入口已移除。其他工具或其他机器的安装状态未核实。

2.0 的安装脚本曾把备份留在 skill 扫描目录内，导致旧版也被发现为同名 skill。2.1 将新备份放入 `~/.agents/skill-backups/`；对已安装的链接，会把旧备份迁移出去，完整保留文件。需要切换安装且已获得授权时，从本仓库运行：

```sh
python3 scripts/install.py
python3 scripts/install.py --apply
```

第一条只预览；第二条执行并打印备份路径。首次安装也可用这两条命令。重复执行不会重复搬移。脚本不会删除备份，不覆盖其他符号链接；建立链接失败时恢复原目录。仅依赖 Python 标准库。

保持此仓库路径稳定；已有发现入口指向该仓库时，在新会话里读取 `ui-taste-skill` 并确认版本为 3.2.0，且不再出现备份目录中的旧入口。没有发现入口时需按对应工具的安装方式单独接入；不能以仓库升级代替安装验证。旧会话可能仍持有旧指令。

## 验证

```sh
python3 -B -m unittest discover -s tests -v
```

Python 3.9+，仅依赖标准库：安装测试在临时目录检查预览、切换、重复执行、恢复及失败回滚，不操作真实安装目录；包检查核对入口元数据、版本、文档链接、离线资源及证据文件哈希。哈希一致仅表示截图对应当前源码，不代表审美通过。

需要重跑教学示例的真实浏览器检查时：

```sh
node scripts/verify-app-craft.cjs
node scripts/verify-references.cjs
```

需要 Node.js 18+ 和已安装的 Chrome/Chromium；找不到浏览器时可用 `CHROME_BIN` 指定可执行文件。脚本不安装依赖，使用隔离临时浏览器配置和仅监听 `127.0.0.1` 的临时服务，不读取用户浏览器配置；完成后关闭服务并清理自己的临时目录。两个脚本分别更新 `assets/app-craft-evidence/` 和 `assets/reference-evidence/` 内的报告与截图，记录源码、截图哈希和页面状态。更新后仍须逐张读图，不能将自动检查或旧读图结论当作当前视觉结论。
