65## 用法
66 
67选中技能，给出页面、受众和必须保留的事实：
68 
69```text
70用 ui-taste-skill 重做这个定价页：三档，中间档推荐，给工程团队评估。
71保留现有文案与价格事实，缺的信息标 [待补]，不要编。
72```
73 
74第一次拿到什么，取决于任务：
75 
76- **开放新设计 / 整体重做**：6–7 版明显不同的关键屏——5–6 版按技能原则（构图/材料/对象表达至少两轴不同，只有配色不同算同一版），另加 1 版自由版：派不加载技能的子代理、只传 brief，模型默认生成，主 agent 只查地板并留派发证据。同等参选，自由版赢就交它；挑定再展开整页。
77- **给了原稿或已认可方向**：原稿即规格，单稿忠实深化。
78- **局部精修**：只改受影响处，不借机翻新整页。

80## 包里有什么
81 
82- [SKILL.md](SKILL.md) — 入口：七条正面原则、统一底子、短清单兜底、任务分流与加载表。
83- `tokens/scale.md` — 间距 / 字号 / 字重 / 圆角 / 阴影 / 动效刻度，全页共用一套。
84- `references/taste-gallery.md` — 两张用户亲手选中的首屏；动笔前看图，借一条主关系。
85- `registers/` — 品类原型 C1–C9、六套排印配方、六套材质配方；判品类取默认，一页内部不混搭。
86- `patterns/` — 5 份页面骨架：定价、营销首屏、仪表、设置表单、表格列表。
87- `references/` — 选读深查：文案表述、工艺地板、视觉来源等。
88- `scripts/` — 可选 DOM 探针（对比度 / 溢出 / 结构 / 能量），默认不跑。
89 
90品类原型与骨架是反复验证过的积累，**不覆盖所有品类**；没覆盖的从内容推导，不硬套。每份 `.md` 另配同名 `.html` 镜像供浏览器阅读，agent 加载 `.md`。
91 
92## 边界
93 
94- **保证下限，不保证上限。** 清单全过只证明「没塌」；好不好由你同视口匿名并排挑。不承诺任何模型必然产出好看界面。
95- **面向网页。** 交付物是 HTML/CSS；原生 App 与 macOS/iOS 控件工艺没有对应模块，需在目标平台另行验收。
96- **探针可选。** 四个 `.py` 只要 python3 标准库 + 本机 Chrome，两个 `.mjs` 需要 Node；不跑就人工测量并如实标明。
97- **安装器支持某客户端 ≠ 已在该客户端验证。** Qoder、Claude Code、Codex 都读 SKILL.md 头部的 description 触发；`_meta.json` 触发词只对 Qoder 有效。
98- **不做组件库。** 只生成这一页需要的，不产出通用 Button / Card。
