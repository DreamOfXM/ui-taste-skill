# 内置依据画廊（离线可看）

## 何时读

选方向前（节点 1）必须**实际打开至少一张**看图，借**一条**主关系。冻结 brief 禁外链、禁照片时，这里是唯一能看的依据；不许用文字想象代替看图。

## 两张样张（都是用户在第二轮冻结对照里亲手选中的首屏，1440×900）

### `assets/taste-gallery/relay-first.png` — 开发工具推广页

- **地面**：浅冷白 + 一眼可见的点阵 + 右上淡蓝光晕。不是平涂。
- **对象**：一张**无边框**的白色摘要卡浮在地面上（大数字 + 一条 bar + 最慢请求 + 失败分类 chip），软投影承担体积。对象没有被关进盒子。
- **标题手势**：重 sans 展示标题 + 蓝色 marker 下划线划在关键词上。
- **铺满**：首屏底部有滚动 cue 行，下一节标题已进入首屏下沿。
- **借哪条**：工具类产品的对象可以是「浮置的摘要卡」；地面用点阵给工程感，不靠深色。

### `assets/taste-gallery/suwen-first.png` — 美妆详情页

- **地面**：暖米白 + 斜向光带 + 瓶后同心圆细线。层次看得见。
- **对象**：琥珀玻璃瓶 + 纸盒浮置，无容器边框；标注线从瓶身指向材质名。
- **标题手势**：衬线展示字 + 字距拉开的眉题。
- **成句**：成分事实合成一段（「共 15 项，前三项标注含量…」），四格事实带整组两条线。
- **借哪条**：对象用材质渲染浮在光里；同类事实成一条带而不是逐行堆。

## 边界

- 借**关系**（地面托住对象 / 对象浮置 / 标题层级 / 首屏完整 / 成句），不抄配色、不抄版式、不抄品类指纹。**先过内容表达三问与主操作克制，再借画面关系**；手势和铺满不得让产品事实更难读。
- 两张都是浅色地面。**深色地面没有内置样张**：按 SKILL.md ③ 现做，地面要托住对象；平涂若对象自身有足够体积也可以，不得为了层次或铺满压过对象。
- 画廊是依据，不是审美上限；与当前 brief 冲突时以 brief 的硬约束为准，并说明放弃了画廊的哪条关系。
