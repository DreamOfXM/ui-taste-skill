# 视觉语言：按任务选关系，不贴风格标签

名称只是检索入口，不是行业定律。先由[任务索引](visual-examples.md)确定用户在做什么，再在这里选一种主导关系；每种语言只解决"这屏靠什么产生美感"，不规定导航模型或控件样式。平台是覆盖层而非第七种风格：原生控件、系统字阶、安全区、焦点与辅助功能适用于所有语言；Web 可以轻盈，原生也可以精密或明快。

每节给出"感觉 → 三组可见关系 → 适合 / 不宜 → 一个相似外观但关系错误的反例"。完整配方与实图拆解随范例增量补充；当前先用作选择与防错入口。

## 亲近而清楚

感觉：温和、可信、不幼稚。关系：可读的中文阅读尺度字块；事实与来源贴近所属对象；中性温和底色加一个有职责的动作色。适合服务、经验、社区、日常健康信息。不宜高频数字分析或强品牌展陈。反例：把每块内容涂成糖果色、来源缩成读不清的微字——外观"亲切"但关系上牺牲了可信与可读。实例见[移动服务拆解](lessons/mobile-service.md)。

## 精密工作面

感觉：秩序、精确、安静但不寡淡。关系：稳定列位让同类对象可比较；行内紧、行间停、详情舒的三种停顿；选择与详情指向同一对象的连续信号。适合资料管理、后台、对象检查。不宜以情绪和影像发现为主的内容。反例：靠把字缩小或加巨大留白冒充精密——外观"干净"但关系上丢了密度层级与任务信息。实例见[工作台精讲](lessons/workbench-relations.md)。

## 编辑式阅读

感觉：有刊物气质、读得深入。关系：标题、正文、旁注按阅读阶段改变密度；受控行长与语义断行；图文共享重心。适合长文、专题、知识出版。不宜高频表格和短任务表单。反例：把入口的大字与宽留白原样带进正文页——外观"统一"但关系上让连续阅读疲劳。实例见[间](visual-examples.md#b-间由排印与材料承担表达的阅读界面)。

## 材料式展陈

感觉：对象本身值得看。关系：真实材料在尺度、裁切与负空间中成为主角；规格安静靠近；浏览有节奏。适合作品、影像、产品目录、创作资源。不宜没有足够材料的纯数据任务。反例：用空占位图或无含义图表撑展陈——外观"高级"但关系上主角不存在。实例见[字间展陈](visual-examples.md#方向工作室同一份内容创造两种完整美感)。

## 明快有序

感觉：积极、轻快、有活力但不吵。关系：大面积色彩或图形承托一个真实对象；清楚字阶与有限形状语言保持稳定骨架；色块有职责、触达明确。适合学习、活动、年轻化工具、有授权品牌语言的产品。不宜高风险状态系统或严肃长时监控的默认皮肤。反例：每张卡都抖动、每个按钮都发光、状态色与品牌色混用——外观"热闹"但关系上活力没有骨架与职责。条件化色值起点见[色彩与明暗](taste-foundations.md#4-色彩与明暗)，须实测对比度。

## 轻盈对象面

感觉：清楚、轻巧、直接。关系：少量稳定对象与安静背景；克制但明确的字阶与精致小图形；少层边界、直接的状态变化。适合单任务工具、轻量查看器、低密度对象操作。不宜把大量字段与批处理强行压进极简外壳。反例：为极简藏掉必要操作与状态——外观"简洁"但关系上任务无法完成。原生与 Web 都可采用，控件仍用平台标准件。

## 同一任务，两种语言

公共图书馆的收藏整理页都保留检索、选择、标签与详情。面向高频研究者选精密工作面，以稳定列位与舒展详情支持重复处理；面向家庭阅读、且项目已有明快品牌与真实书封素材时选明快有序，以成套色块、封面比例与清楚文字组织同样能力。选择来自受众、材料、品牌与使用频率，不是"图书馆必须安静"。哪一种更好仍由同内容关键屏判断。

## 组合与覆盖

主语言决定整体空间、排印与材料；补充只解决一个具体缺口（如精密工作面借编辑式阅读的正文行长可以成立）。同时混入展陈大图、糖果状态色、玻璃表面与超大标题而无任务理由则不成立。覆盖顺序：用户授权/事实/安全底线 → 已确认品牌与指定关系 → 任务结构＋语言＋材料 → 局部覆盖 → 默认值最后补缺。换品牌色不自动换行高与图标；换字体必须重校字块与组件尺寸，但不自动重做信息结构。
