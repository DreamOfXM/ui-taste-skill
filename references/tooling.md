# 运行与可选工具

核心流程不依赖第三方启动器、付费服务或特定目录。优先使用当前工具列表中的浏览器、读图与目标平台运行工具。

## 参考和截图

- 网页用本地 HTTP 服务运行；用实际目标视口截图、操作并检查控制台。静态 HTML 示范也需检查窄屏和关键状态。
- 原生 App 用目标运行环境或模拟器；HTML 模型不等于原生验收。
- 每次复查用当前源码对应的截图。能生成截图却不能读取图像时，明确交接给可读图执行者或标为待验证。
- 参考来自用户、项目或真实可访问材料。外网不可用就使用本地样例，不伪称已经研究某品牌；下载图片前核对来源与使用权限。
- 图像生成可制作概念或原创材料，不能替代真实界面截图；无需为了“高级”强制使用生成图。字体、照片与图标优先沿用项目资源，缺材料再按工具与授权获取，不擅自上传私密项目素材。
- 给不能读图的实现者传递视觉执行包：图的实际观察、目标视口、区域关系、字体角色、素材路径、状态与不可变约束；由具备读图能力的环节检查结果。不要因为某个工具可以截图就宣称所有模型都能视觉验收。

## 读取其它 skill

用当前会话提供的 skill 基目录定位文件，不硬编码 `~/.agents` 或某台机器路径。先确认资源存在，再读本次需要的段落；不要递归加载整套资料。

本流程借鉴 `impeccable` 的屏幕任务分类、完整视觉语言、内容材料和有限轮次复查；不继承其随机方向、强制问答、字体/风格绝对禁令或 CLI 依赖。借鉴关系而非把另一个 skill 原封不动嵌套进来。

脚本运行前核实实际接口与行为；会下载、安装或执行第三方程序的启动器不能作为读设计文档的必经步骤，须有对应授权。文档中的命令名不自动意味着存在同名 CLI。

## 通用网页取证

[取证脚本](../scripts/capture-ui.cjs)检查实际产物，不只检查本包教学页。需要本机Node与Chrome/Chromium；缺浏览器可设置 `CHROME_BIN`，不自动下载安装。先启动项目本地服务，再运行：

```sh
node <skill-dir>/scripts/capture-ui.cjs --url http://127.0.0.1:4173/ --source ./index.html --out ./evidence/run-01 --width 1440 --height 960
```

仅接受本机回环页面入口；使用独立临时浏览器配置，不读取用户登录资料。输出目录的父目录须已存在，输出目录须新建或为空，路径不能经过符号链接；旧截图不会被覆盖。`--source`记录所给文件的SHA-256，不证明服务器实际发送了该文件，也不哈希所有依赖；多文件工程另外记录Git提交与未提交diff。页面仍可能加载外部资源，这不是网络沙箱；不以缺图冒充最终效果。

可用 `--steps ./steps.json` 记录实际输入与多个状态：

```json
[
  {"action":"capture","name":"desktop"},
  {"action":"fill","selector":"#search","text":"不存在的对象"},
  {"action":"capture","name":"empty"},
  {"action":"fill","selector":"#search","text":""},
  {"action":"viewport","width":390,"height":844},
  {"action":"capture","name":"narrow"}
]
```

选择器按当前项目填写，不把例子当通用测试。截图记录视口、源码/图片哈希、浏览器和步骤；控制台错误、横向溢出用于定位问题，不用于自动美感打分。脚本不替你验收业务结果或看图，也不会证明所有键盘、触达、缩放和原生状态都通过。

## 维护本包

从仓库根目录运行，使用本机已有 Python、Node 与 Chrome/Chromium；缺失依赖时报告未运行，不自动安装：

```sh
python3 -B -m unittest discover -s tests -v
node scripts/verify-app-craft.cjs
node scripts/verify-references.cjs
```

后两项会启动临时本地服务、使用独立临时浏览器配置、操作教学样例并更新各自的截图与 JSON 证据；不会访问用户浏览器配置或外部站点。改示例后先重新取证再跑包测试。

包检查、DOM 断言、截图哈希只验证对应工程事实，不给审美打分。历史 `beauty_gate.py`、`BEAUTY_RUBRIC.md` 与固定投票协议不属于本流程，不因它们的风格阈值改画面。未运行的命令不能写成通过。
