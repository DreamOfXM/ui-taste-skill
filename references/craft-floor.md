# craft-floor：不可协商的地板

这个文件和"品味"无关。它列的是**低于这条线就是坏掉**的项。

单独成文件的理由有两个：

1. **保持 thesis 和账本的纯度**。地板项不参与取舍——不存在"用对比度换呼吸感"这种交易。把它们混进账本，会让"取舍"这个概念稀释，变成什么都能量化交换。
2. **它们可以机械检验**。S5 里这些项不看主观判断，逐条对数值即可。

判定方式：任何一条不满足，S4 的成稿直接不通过，不进 S5 的七问。**地板不过，谈不上品味。**

---

## F1 文字对比度

| 文本类型 | 最低 | 说明 |
|---|---|---|
| 正文（<24px 常规 / <18.66px 粗体） | 4.5:1 | WCAG AA |
| 大字（≥24px 常规 / ≥18.66px 粗体） | 3:1 | |
| 图标、边框等非文本 | 3:1 | 纯装饰除外 |

**两个高频违规**：

- `#9CA3AF` 配纯白 = **2.54:1**。这是 Tailwind `gray-400`，是 AI 生成页面里出现频率最高的次要文字色，也是不合格的。合格替代：`#6B6F76` on `#FBFAF7` = 4.84:1。
- 用主色做正文，主色只够 3:1（`#0F5F52` on `#FBFAF7` = 7.24:1 合格，但很多品牌色不合格）。主色能不能当文字色，必须实测，不能看"深浅感觉"。

**实测命令**（不要心算，心算会错）：

```python
def lin(c):
    c = c / 255
    return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4

def lum(h):
    h = h.lstrip('#'); r, g, b = (int(h[i:i+2], 16) for i in (0, 2, 4))
    return 0.2126*lin(r) + 0.7152*lin(g) + 0.0722*lin(b)

def ratio(a, b):
    la, lb = lum(a), lum(b)
    return (max(la, lb) + 0.05) / (min(la, lb) + 0.05)
```

## F2 点击区

| 场景 | 最小尺寸 |
|---|---|
| 触摸为主（移动、平板） | 44 × 44 px |
| 指针为主（桌面，紧凑工具） | 32 × 32 px |

两个违规形态：视觉上只有一个 16px 图标、实际热区也只有 16px（应为图标外扩 padding 补足）；表格行内操作按钮紧密排列，热区重叠导致误触。

**允许视觉小于 44，但热区必须 ≥44**，用 padding 或伪元素扩展。

## F3 焦点可见

`:focus-visible` 必须有可见样式，且不能只靠浏览器默认（被全局 `outline: none` 干掉后就没救了）。

合格做法：`outline: 2px solid <强调色>; outline-offset: 2px;`
违规做法：`*:focus { outline: none }` 且无替代。

键盘用户靠这个导航。删掉它等于让一部分人无法使用——但视觉上看不出来，所以最容易被漏掉。

---

## F4 字号与行高

| 项 | 下限/区间 |
|---|---|
| 正文 | ≥14px（中文 ≥14，英文 ≥15 更稳） |
| 辅助文字 | ≥12px，且必须满足 F1 |
| 正文行高 | 1.5–1.65 |
| 标题行高 | 1.05–1.25 |
| 中文段落 `letter-spacing` | 0 或 ≥0.01em（负值会让中文糊在一起） |

违规形态：12px 灰色说明文字，同时违反 F4 和 F1——这是"看起来精致"的经典做法，代价是没人读得清。

---

## F5 动效

| 项 | 要求 |
|---|---|
| `prefers-reduced-motion: reduce` | 必须处理，降级为无位移/无缩放 |
| 微交互（hover、按下、toggle） | 120–240ms |
| 入场、页面切换 | 300–500ms |
| 超过 500ms 的过渡 | 必须有 `easing` 曲线说明，不能线性 |

线性缓动的 400ms 会让界面"发木"——这是"有动效但不好用"的主因。

---

## F6 文本溢出

任何容器都必须回答"文字比预期长怎么办"：

- 单行：`text-overflow: ellipsis` + `white-space: nowrap` + `overflow: hidden` 三者齐全
- 多行：`-webkit-line-clamp` 或 `overflow-wrap: anywhere`
- 数字列：`font-variant-numeric: tabular-nums`，否则右对齐会参差

违规形态：中文标题遇到英文长单词撑破卡片；价格列右对齐但数字宽度不一。

多语言场景额外要求：德语/俄语文本比中文长 40–80%，按钮宽度必须能容纳，或用 `min-width` 而非固定宽度。

---

## F7 加载与占位

- 图片必须有 `width`/`height` 或 `aspect-ratio`，防止布局抖动（CLS）
- 异步内容必须有骨架或占位，不能白屏后突然跳出
- 字体加载：`font-display: swap`，且 fallback 字族的字宽要接近，否则切换时跳行

---

## F8 语义与键盘

- 可点击元素用 `<button>` / `<a>`，不用 `<div onClick>`
- 图标按钮必须有 `aria-label`
- Tab 顺序与视觉顺序一致
- 表单 `<label>` 与控件关联（`for`/`id` 或包裹）

这四条在 S5 里逐条检查，因为它们**看不出来但会坏**。而且 AI 生成页面几乎必犯第一条。

---

## 与账本的关系

地板项在账本里以 `F1`–`F8` 编号出现在「依据」列，且「放弃」列写 `无，此为地板`。

这是账本里唯一允许放弃列为空的形态。除此之外任何空值都作废。
