# S5 回读门：整体感怎么取证

输出的记录并入 `design/03-critique.md`，每版一节。

**这一门不打分。** 它只回答一件事：这页的规矩和破例，一个没看过我理由的人能不能只看画面读出来。读不出来就是不过，回去改。

---

## 为什么必须另立一门

十一问测的全是**元素属性**：字号几档、饱和度多少、落点几处、材质几类。这些能直接量，所以做成了硬门。

好坏是**关系属性**：视线先落哪、这块大是因为重要还是因为旁边空、这个数字和那句文案是不是在说同一件事。这些量不出来，只能取证。

0.3.1 的结构性错误是**把门全放在能测的那一半**：十一道硬门查元素，关系只留了两条没判据的建议。结果六版实跑都过了门，却都塌回同一个大数字——因为 G0 那句主张写完之后，**没有任何一问回读它**。

再加第十二道数字门只会重复同一个错误。整体感是 UI 与文字搭配出来的感觉，不是元素检查的总和。

**高级感 = 页面自己立的规矩站得住 + 破规矩的地方破得有理由。**

- 规矩指**成稿画面**，不是账本。账本是我写的，页面是读者看的，两者可以完全对不上。
- 破例**可以多处**，一处也行五处也行，不设数量门。
- 判据不是几处，是**每一处的理由能不能只看画面就说出来**。需要我开口解释才成立的破例，就是失败的破例。

---

## 规矩从哪来

读者要说得出的"这页自己的规矩"，来自三个已经在流程里的东西，不需要新造：

| 来源 | 在哪一步定 | 读者看到的是什么 |
|---|---|---|
| 借的那个类型自带的规矩 | G0 主张句「借了 ___」 | 杂志的栏宽与引言、仪表的读数与阈值、清单的勾选与完成态 |
| 成组落地的配方 | S3 的 `S_` 表面七项 + `P_` 排印六项 | 统一的线宽、曲率、字级阶梯、留白节奏 |
| 密度契约 | S3 的密度行 | 每块空白干什么、两栏怎么配重 |

**三者必须成组落地，读者才可能读出规矩。** 一版内部混搭两套配方，读者说出的会是"这页好像没什么规矩"——那不是读者不懂，是页面真的没有。

---

## 破例清单（G0 落盘，S3 逐条进账本）

每套方向至少一处，**不设上限**。每处三字段齐全，缺任一字段该处作废：

```markdown
- 主关系主张：借了「仪表」这个已存在的类型，它自带的规矩是「读数等宽、按阈值着色、永远占据固定栅格」
- 破例清单：
  1. 破在哪：首屏左缘那个 11.6 GB 的数字
     破了哪条：读数本该等宽落在栅格里，它却用了比正文大 5 倍的比例字体，且独占左半屏
     为什么该破：文案写的是「没量到 11.6 GB」——这是全页唯一一处承认自己做不到的地方，
                 也是 brief 字段二那个唯一任务的答案。它不是又一个读数，它是结论。
  2. 破在哪：「未逐项列出」那两枚虚线胶囊
     破了哪条：仪表不该有手绘感的虚线，全页其余都是 1px 实线
     为什么该破：这两处标的是"量不到的部分"，实线会读作"已确认"，虚线才读作"存疑"。
                 线的性格在这里承担语义，不是装饰。
```

**理由合格与否，对照这张表：**

| 不合格（画面上找不到依据） | 合格（指向画面上的具体内容或文案） |
|---|---|
| 为了有层次 | 文案说这是全页唯一的结论，所以它比其余读数大 5 倍 |
| 为了高级感 | 这一栏是用户每天唯一要看的信息，所以它常驻右缘不随页面滚 |
| 为了呼吸感 | 这块空白隔开的是"已确认"和"存疑"两组，不是随便留的 |
| 为了视觉冲击 | 这个数字是 0，而同类产品都写"精准识别"，反差就是产品本身 |
| 借鉴了某大厂 | 借的是它的栏宽关系，因为本产品也是长文 + 侧栏事实卡 |

**"借鉴了某大厂"不是理由，是出处。** 出处写进账本的「依据」列，理由必须说清那个关系在本页换来了什么。

S3 记账时，每处破例各占一行，「依据」指向内容事实（`C_`）或文案原文，「放弃」写清破了这条规矩损失了什么。**破例没有代价就不是破例，是混乱。**

## 盲看交接包

**交出去的东西，只有这四样：**

1. 一句话任务：用户要对什么对象完成什么动作。
2. 硬约束：必须保留哪些事实与能力、目标视口、平台。
3. 截图：同视口首屏 + 本产品最难那一屏 + 窄屏，**全分辨率 PNG，文案要读得清**。缩略图不行——读不清文字就没法判断"理由能不能从文案里读出来"。
4. 有原稿 / incumbent 时一并给出（这是任务输入，不是我的理由）。

**绝不交出去的东西：**

- 账本、主张句、破例清单、`00-direction.md`、`01-thesis.md`
- 我为什么这么做的任何解释
- 带设计意图的文件名（`v3-借仪表.html` 会泄露答案）→ 截图统一命名 `screen-a.png` / `screen-b.png`
- 哪一版加载了 skill、哪一版是基线

**继承了你的理由，它就继承了你的辩护。** 这是这一门唯一不能妥协的地方。

截图命令（本机 headless Chrome，视口按任务定）：

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
  --force-device-scale-factor=1 --window-size=1440,900 \
  --virtual-time-budget=9000 --screenshot=screen-a.png file:///abs/path/page.html
```

## 三问（原文照发，不要改写）

```text
你要评审一个界面。我没告诉你我为什么这么做，请只根据画面回答。

任务：<用户要对什么对象完成什么动作>
约束：<必须保留的事实与能力、视口、平台>
图片：<screen-a.png 首屏 / screen-b.png 最难屏 / screen-c.png 窄屏>

请按顺序回答，每问都要指到画面上的具体位置：

一、这页自己的规矩是什么？
    它借的是哪一类东西（杂志 / 仪表 / 清单 / 说明书 / 账本…）？
    它的字级、线、面、留白按什么规律重复？
    说不出规律就直接写"看不出规矩"，不要替我编一个。

二、哪几处不合这规矩？
    逐条列，位置 + 它破的是哪条。不设数量上限，一处也写，五处也写。
    一处都没有就写"全守规矩"。

三、每处为什么该破？
    只准用画面上看得到的东西回答，包括文案原文。
    读不出理由的就写"读不出理由"。不要猜我的意图，不要写"为了层次/为了高级"。

四、另外两件事（与上面三问分开答）：
    第一眼落在哪？有没有一处关系值得保留？
    最拖累画面的至多两处：位置 → 根因 → 改动 → 预期结果。

最后给一个下一步：保留方向 / 改局部 / 重做 / 证据不足。
```

**第四问是原来的「独立看图」，并进同一次盲看，不另开一轮。** 三问管规矩与破例，第四问管落点与缺陷，两者不重复。

## 记录格式（原话照录，不打分）

```markdown
## v3 · 回读门

- 执行者：独立实例（子代理），未收到账本 / 主张 / 破例清单
- 交接包：screen-a.png（1440×900 首屏）、screen-b.png（定价三档）、screen-c.png（390 窄屏）
- 独立性：独立 / **非独立**（没有独立执行者时必须标）

**一、规矩（原话）**
> 「……」

**二、破例（原话，逐条）**
> 1. 「……」
> 2. 「……」

**三、理由（原话，逐条对应）**
> 1. 「……」
> 2. 「读不出理由」

**四、落点与缺陷（原话）**
> 「……」

**判定**：过 / 不过（不过的写清是下面哪一种，回哪一步）
**与我的破例清单的差异**：我写了 3 处，读者读出 2 处；第 3 处（右缘窄柱）读者没当成破例，
因为它以为整页都是窄柱栅格 —— 这说明画面传达的规矩和我主张的不是同一条，记进已知短板。
```

**最后那一栏必须写。** 读者说出的规矩和我主张的不一致时，**以读者说出的为准**——规矩是页面传达的东西，不是我意图里的东西。不一致本身就是一个真实发现：要么改画面对齐主张，要么明写接受并说清代价。

## 判据：三种不过，回的地方不同

| 不过的形态 | 说明什么 | 回哪一步 |
|---|---|---|
| **规矩说不出**（第一问答"看不出规矩"） | 页面没有成组的系统，配方混搭或根本没落地 | 回 **S2/S3**：重选一套配方并成组落地。**不是回 S4 加装饰** |
| **破例读不出理由**（第三问出现"读不出理由"） | 破例存在但不承担语义，读者只看到不一致 | 回 **G0** 重立破例，或回 **S3** 换一个能自己说话的承载元素（改文案、改位置、改它承载的事实） |
| **全守规矩**（第二问答"一处都没有"） | 页面完全按默认值走，这是平庸的典型形态 | 回 **G0** 重立主张：这版没有自己的主张。**不是回 S4 加颜色** |

**改完必须重新盲看**，且换一个没看过上一轮的实例。用同一个实例复看，它会记得自己上次的答案。

**三种不过都不删版。** 门负责拦，不负责淘汰——回对应阶段改到过为止。

---

## 这一门判不了什么

**它只判失败，判不了优秀。** 规矩说得出、破例理由读得出，只说明这页"有自己的道理"，不说明它比另一页更值得装。

优秀那一步靠**第三层：同视口匿名并排二选一**（见 `critique.md` 的版间并排看图）。问的是「你愿意装哪个」，不是「哪个分数高」。结论归用户。

**不要给回读门加分数。** 一旦把"读出几处破例"变成阈值，它就退化成第十二道元素门，同一个错误再犯一遍。

---

## 成本与降级

- 每版一次盲看，一个独立实例。5–6 版就是 5–6 次，**这是每版各一遍，不是抽一版代表全部**。
- 上下文不够时**减版不减门**：宁可交 5 版都回读过，不交 6 版里有 2 版没回读。
- 没有独立读图执行者时，按同一流程自看，并在报告里**标明"非独立"**。非独立回读不构成整体感结论，必须同时写进已知短板。
- 生产者自评不能单独作为审美结论——这一条在三层验收里都成立。
