# 主动设计美感，而非修到没有错误

新设计和整体改版使用本流程。范围、读图能力与验证预算遵循主入口；局部任务不强制概念探索。

## 1. 让产品内容产生方向

先走通“看见对象 → 理解 → 判断 → 动作 → 结果”，分清操作、阅读、说服或体验。任务决定必须支持什么，不预先决定只能长成哪种常见页面。

收集三个有潜力的方向主张，每个只写“内容依据 → 视觉关系 → 体验结果”。来源可以是产品的工作方式、受众熟悉的出版/图形传统、物件与空间、同类优秀工具，也可以来自跨行业的组织手法；文化联想要说明是设计假设，不冒充用户事实。不要只是列“极简、科技、轻奢”。

例如同一标本库：

- **像展陈一样浏览**：字样是实际内容 → 不同尺度的标本与克制元信息共同构图 → 先感受差别，再深入判断。
- **像仪器一样比较**：用户反复选择与检查 → 紧凑目录、稳定的大试样区、清晰参数 → 每次切换都精确、连贯。
- **像编辑目录一样阅读**：内容有分类与解释 → 文字块、分组轴线、疏密段落 → 让比较变成有节奏的阅读。

它们不是所有产品的三个模板。换成财务审核，方向应从差异、风险与复核关系生长，不硬套标本展陈。已给明确原稿则走[参考适配](visual-calibration.md)，不为原创性偏离它。

选最有根据的两个方向做同内容、同状态的完整关键屏；较弱者不能故意潦草。比较哪一个更有吸引力、内容更清楚、气质更贴切，允许某一项各有所长。自主授权时作出取舍继续；已有认可方向或预算受限时只深化一条，并说明理由。

## 2. 组合视觉语言，而不是收集装饰

为每个候选选择一条主导关系，让其它决定共同支持它：

| 设计杠杆 | 可执行的正向决定 | 画面怎样变好 | 边界 |
|---|---|---|---|
| 构图张力 | 放大真正的核心对象；用偏置、成组或跨栏建立一个主落点，以次级对象平衡 | 视线有停留、有路线，画面不是均匀平铺 | 不靠遮挡操作、不相关大标题或随机错位 |
| 排印形态 | 用真实标题试字，决定字块宽度、断行、字面大小与轻重；正文和标注形成另一种稳定纹理 | 文字既传意，也形成可欣赏的形状与节奏 | 中文不机械负字距；不能用缩小正文腾空间 |
| 空间节奏 | 内容内部收紧，主题之间展开；把安静区放在有意义的位置 | 密与疏互相衬托，而不是全页一样空 | 列表工作的节奏可在行组与检查器间，不强加滚动叙事 |
| 色彩场 | 决定色彩是大片材料、局部行动还是状态编码，再安排面积和明暗 | 颜色组织画面和情绪，不只是点缀按钮 | 不规定永远中性底＋单强调色；状态仍可辨 |
| 材料质感 | 先确定图像、字样、图表或真实产品画面的质地与裁切，再安排界面 | 内容有不可替换的细节，产品不再像通用外壳 | 质感不等于噪点、玻璃与阴影叠加 |
| 光学工艺 | 在实际字号检查图标视觉中心、中文字面、圆形与直边、边界强弱 | 精确而不僵硬，细节彼此照应 | 不为极小光学校正推翻组件系统 |
| 连续交互 | 定义一次选择/展开前后的对象位置、焦点、强调和反馈，再安排过渡 | 画面变化有因果、可追踪，操作本身也优美 | 不逐卡入场，不为动效制造假进度或等待 |

不必每项都强烈。选最能创造美感的少数关系主导，其余做精；“每块都有记忆点”只会让整体争吵。所谓高级来自比例、材料与完成度相互配合，不来自一套昂贵色名。

## 3. 先做材料与样片

用最长真实标题、一条最复杂对象与真实图像先做局部样片：标题＋说明＋一个控件＋一个对象/图片。一次确认文字的字面与行距、图像裁切、边界和表面是否属于同一套语言，再把它铺到关键屏；不要先建庞大 token 表。

照片任务先获得照片，作品浏览先准备作品，工具任务用真实任务对象或明确标示的示例数据。素材不可用时换一个仍有表达力且能实现的方向，不拿伪截图、空框或粗糙矢量冒充精细材料。不要为追求真实而自动替换已认可的优秀示意。

有图像生成能力时，可制作概念画面或缺少的原创素材，但它们分别是设计假设与素材，不是浏览器证据；字体、按钮、布局和响应式仍需实际实现。没有图像生成能力也能用排印、可实现图形与内容设计出色，不默认降低目标。

## 4. 把方向交给实现，而非让实现重新猜

填写主入口的短设计卡；给出足够完成当前屏的具体初值。例如：

```text
场景：1440×960的字体标本库，六条记录，浏览/检查/收藏。
选择：展陈方向，字样是主角；元信息安静但可读。
结构：导航与工具占顶部；主区约3:1分配给标本集合与当前详情。
文字：集合字样约20–72按字形与字长适配，名称13，说明11；中文按语义断行。
材料：本机字体实际渲染；不借虚构图片或商标制造品质。
状态：选中后同一字样在详情展开；390宽进入详情并可返回原位置。
验收：字样与注释形成清楚的尺度对比，空白服务字样，不稀释列表能力。
```

这些初值只对应这个任务；工具表格、移动消息页和品牌站不能照抄。具体两种构图可实际操作[字间方向工作室](../assets/variant-board.html)，再读[关系拆解](visual-examples.md)。

实现阶段按“大区域与字块 → 材料与表面 → 控件细节 → 状态与窄屏”推进。不要同时改掉参考的构图、字号、图像与颜色，再声称是在还原；也不要把有力量的方向逐步稀释成常见组件库默认值。

## 5. 给执行困难的模型更明确的支撑，不降低审美目标

按观察到的能力与工具选择路径，不按模型名字或 Flash/Max 标签猜测：

- **能独立读图和设计**：自行探索、选择、运行与复看，用真实作品校准，不自评虚构分数。
- **能实现但总在选型或还原时漂移**：将一张已选画面与上述执行包一起交给它；按区域给尺寸、字体角色、素材路径、状态和不可变关系，每次只完成一个关键屏。需要的帮助是减少同时猜测的决定，不是只许做简陋页面。
- **不能直接读图**：由实际看图的执行者提供画面关系与规格；实现者据此编码，视觉结果交回有读图能力的环节。没有这个环节就标待验证，不冒充闭环。

失败时定位到底是方向没吸引力、材料不够、实现丢失关系还是执行链缺口；改那个层级，不再追加“更高级一点”的空指令。可用工具与上下文预算仍是实际边界，任何路径都不保证所有模型同等出色。

## 6. 先判断魅力，再扩展范围

完整关键屏要能回答：哪里让人愿意停留或继续操作？这种美感由什么具体关系创造？换成通用排版会损失什么？精密工作页的答案可以是稳定字阶、紧凑列位和连续状态的整体，不强求奇特装饰。

与同条件参考比较并按[审美判断](review.md)纠偏；成立后先迁移到最密集内页与展开状态，再推广其余范围。若好看只存在于大标题或素材封面，进入真实内容就散掉，这个方向尚未完成。
