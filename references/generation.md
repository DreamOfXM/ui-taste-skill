# 把内容推成作品，而不是套进外壳

新设计与整体改版用此流程，局部任务不强制探索。用户原稿优先。先把执行预算分给取材、实现和实际看图，至少留一次修正与复验；别把预算花光在方向说明上。

## 1. 找到产品自己携带的美感

先走通“对象 → 理解 → 判断 → 动作 → 结果”，盘点可以真正展示的东西：字样、影像、账目、时间关系、作品、空间或操作过程。把没有的材料和不能编造的事实划掉。真实截图不自动好看，原创图形也不自动虚假；关键是它是否诚实、有用、经过设计。

写三个短推导，每个只有“内容证据 → 视觉关系 → 体验结果”。不要从审美形容词或主题名开始。例如：

- 多份文献有不同年代与脚注 → 连续正文旁挂窄索引、页码与批注共轴 → 读得深入且随时能定位。
- 用户反复比较波形 → 稳定坐标与大工作区，参数紧贴选中片段 → 感到精确，切换时不丢上下文。
- 陶器的轮廓与釉色就是内容 → 不同视角和负空间组成展陈，规格安静靠近 → 先看到物件的区别再选择。

同样一组内容可以有不同优点。不要预设“营销=大字+照片”“软件=侧栏+四卡”“高级=奶油衬线”；也不要为反套路故意破坏熟悉的操作。

**筛选两条**：它们是否突出不同的真实价值？删去品牌名以后，关键对象和结构是否仍与任务相符？这是检查内容有没有参与设计，不是禁止常规布局。材料做不到、平台不允许或只能靠空白与装饰撑起来的方向先淘汰。

## 2. 先试最难的一块材料

用最长真实标题、一条最复杂对象、一个主要控件与核心材料做局部样片；在目标字号下实际渲染，不以缩略稿定细节。一次解决最容易让整屏廉价的东西：

| 材料 | 先做的决定 | 看见什么才继续 |
|---|---|---|
| 照片、视频、产品画面 | 先选主体和裁切，再定文字位置；先拿到文件，不用空框等素材 | 主体清楚，图像与字块共享重心，界面不是悬在任意背景上 |
| 标题、出版、语言 | 实际字体试排最长标题，确定字块轮廓、行数与注释的反差 | 断行有语义，字块有形，正文不被挤成窄缝 |
| 表格、工作票、时间线 | 同时放普通行、长行、选中行；先分清对象、状态与数值角色 | 密度高但视线有路径，长内容不会冲散列位 |
| 图形、图表、原创字样 | 用真实含义决定图形，再测试小尺寸及状态变化 | 图形提供认识或表达，不靠虚构数据和装饰刻度撑场面 |

照片不可得时选择内容能支持的另一种有力构图，不降级成占位卡片；图像生成可提供原创材料或概念稿，但不是运行证据。中文/混排或试字不成立时读[排印工艺](typography.md)。

## 3. 一条主关系，带动一组决定

让一个少数关键关系主导，其余为它服务。不是每块都做成焦点，也不是把所有东西弱化。

| 主关系 | 一起调整 | 不成立的替代 |
|---|---|---|
| 尺度差产生展陈感 | 核心对象大小、陪衬字阶、空白位置、裁切 | 单独放大标题，内容仍平均分栏 |
| 密疏差产生精密感 | 列位、行组、详情呼吸、状态对比 | 把字缩小，或用大留白删掉工作信息 |
| 排印产生阅读节奏 | 字块宽度、断行、轻重、正文与旁注轴线 | 只换“高级字体” |
| 材料成为色彩场 | 素材色调、表面面积、文字明暗、控件边界 | 给每张卡加一套渐变 |
| 动作延续对象身份 | 起点终点、位置与焦点、选中强调、可中断返回 | 无关淡入、逐项登场、假进度 |

强表达也可以是稳定精密的一整面数据；不强求一个怪异“记忆点”。反之，丰富色彩与强材质有明确作用时，不为显得克制把它们洗成灰色。

## 4. 将主张变成能守住的实现锚点

填主入口的设计卡，只锁最能影响当前屏的三处。每处连起“区域/组件 → 具体关系 → 初值 → 最长内容或窄屏怎样保持”，不先造庞大 token 表。

```text
示例：声音剪辑工作台，1440×960；不是通用配方。
工作区 .timeline：波形是主角，左轨道名固定176，右参数区280可收起。
字块 .clip-name：对象名两行内可辨；时码等宽数字，说明随文本字体。
状态 .clip[aria-selected]：只强化当前片段边界与参数标题；播放不夺焦点。
窄屏：轨道目录进入片段详情，返回保留片段与滚动，不把整张桌面缩小。
```

先做大区域与字块，再做材料/表面、控件、状态。不要在实现中同时改掉尺度、裁切和空白，却仍把它叫同一方向。沿用项目组件时主动调到设计关系，而不是默认值一出现就放弃设计。

## 5. 用一轮可见实验替代十句“更高级”

两条方向用同内容、同视口、同状态比较。较弱者不能故意潦草；自主任务自己选，保留另一条真实优点，不等用户当设计师。预算只够一条时，拿最不确定的一处做同内容的变化，不铺开第二套产品。

**做一个能证伪的改动**：先说清“哪里普通、哪个关系造成、改变后应看见什么”，保持其它大变量不变，运行并排看。改善成立才保留，不以改动量算进步。例如：

- 标题与摘要互相争夺：保持字体和颜色，先改字块宽度与断行；看主次是否出现，不先加装饰。
- 展品被框架压小：保持全部展品与操作，把重复包围框转成共同轴线；看内容是否更有存在感。
- 列表很整齐但像报表堆叠：保留行数和字段，把当前对象与其动作合成连续工作区；看任务是否终于主导构图。

如果只是组件细节变化、缩略整屏仍无主次，就回到构图或材料层；如果整体成立，停止翻新方向。看图评审按[评审流程](review.md)，不得通过增加形容词宣称实验成功。

## 6. 先过压力屏，再推广

将选定语言应用到最难内容，而不是第二个漂亮封面：最长名称、最多列/最密对象、选中展开、一次操作与返回、窄窗。检查哪项原先依赖的关系被挤掉，主动转换布局而不是等比例缩小。

窄屏同时守住两件事：**对象还能被认出，用户能尽早开始判断**。帮助辨认对象的图像不要一律 `display:none`，可改成紧凑横幅、局部裁切或与标题并排；纯装饰则可移除。检查实际首次决策所需的名称、区别、状态和动作出现在哪里，优先合并重复导航、调整图文顺序，不把整张长页硬塞进首屏，也不为多露一行毁掉构图。

记录可直接定位的一组“当前帧 → 关系丢失 → 改动 → 新帧”。只有指定原稿时以忠实还原为先；开放设计保留有效关系、淘汰无效假设。整体失败在原范围重做一次关键屏，仍不成立就如实说未达。

执行者能实现却常漂移时，给它已选图和上述锚点，减少同时猜测的决定；不能读图时交给有读图能力者复核。没有图片与操作证据的环节仍待验证，不按模型名字推断水平，也不把预算用尽当作优秀。
