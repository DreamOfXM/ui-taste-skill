14## F1 文字对比度
15 
16| 文本类型 | 最低 | 说明 |
17|---|---|---|
18| 正文（<24px 常规 / <18.66px 粗体） | 4.5:1 | WCAG AA |
19| 大字（≥24px 常规 / ≥18.66px 粗体） | 3:1 | |
20| 图标、边框等非文本 | 3:1 | 纯装饰除外 |
21 
22**两个高频违规**：
23 
24- `#9CA3AF` 配纯白 = **2.54:1**。这是 Tailwind `gray-400`，是 AI 生成页面里出现频率最高的次要文字色，也是不合格的。合格替代：`#6B6F76` on `#FBFAF7` = 4.84:1。
25- 用主色做正文，主色只够 3:1（`#0F5F52` on `#FBFAF7` = 7.24:1 合格，但很多品牌色不合格）。主色能不能当文字色，必须实测，不能看"深浅感觉"。
26 
27**实测命令**（不要心算，心算会错）：
28 
29```python
30def lin(c):
31    c = c / 255
32    return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
33 
34def lum(h):
35    h = h.lstrip('#'); r, g, b = (int(h[i:i+2], 16) for i in (0, 2, 4))
36    return 0.2126*lin(r) + 0.7152*lin(g) + 0.0722*lin(b)
37 
38def ratio(a, b):
39    la, lb = lum(a), lum(b)
40    return (max(la, lb) + 0.05) / (min(la, lb) + 0.05)
41```

45## F2 点击区
46 
47| 场景 | 最小尺寸 |
48|---|---|
49| 触摸为主（移动、平板） | 44 × 44 px |
50| 指针为主（桌面，紧凑工具） | 32 × 32 px |
51 
52两个违规形态：视觉上只有一个 16px 图标、实际热区也只有 16px（应为图标外扩 padding 补足）；表格行内操作按钮紧密排列，热区重叠导致误触。
53 
54**允许视觉小于 44，但热区必须 ≥44**，用 padding 或伪元素扩展。

58## F3 焦点可见
59 
60`:focus-visible` 必须有可见样式，且不能只靠浏览器默认（被全局 `outline: none` 干掉后就没救了）。
61 
62合格做法：`outline: 2px solid <强调色>; outline-offset: 2px;`
63违规做法：`*:focus { outline: none }` 且无替代。
64 
65键盘用户靠这个导航。删掉它等于让一部分人无法使用——但视觉上看不出来，所以最容易被漏掉。

69## F4 字号与行高
70 
71| 项 | 下限/区间 |
72|---|---|
73| 正文 | ≥14px（中文 ≥14，英文 ≥15 更稳） |
74| 辅助文字 | ≥12px，且必须满足 F1 |
75| 正文行高 | 1.5–1.65 |
76| 标题行高 | 1.05–1.25 |
77| 中文段落 `letter-spacing` | 0 或 ≥0.01em（负值会让中文糊在一起） |
78 
79违规形态：12px 灰色说明文字，同时违反 F4 和 F1——这是"看起来精致"的经典做法，代价是没人读得清。

83## F5 动效
84 
85| 项 | 要求 |
86|---|---|
87| `prefers-reduced-motion: reduce` | 必须处理，降级为无位移/无缩放 |
88| 微交互（hover、按下、toggle） | 120–240ms |
89| 入场、页面切换 | 300–500ms |
90| 超过 500ms 的过渡 | 必须有 `easing` 曲线说明，不能线性 |
91 
92线性缓动的 400ms 会让界面"发木"——这是"有动效但不好用"的主因。

96## F6 文本溢出
97 
98任何容器都必须回答"文字比预期长怎么办"：
99 
100- 单行：`text-overflow: ellipsis` + `white-space: nowrap` + `overflow: hidden` 三者齐全
101- 多行：`-webkit-line-clamp` 或 `overflow-wrap: anywhere`
102- 数字列：`font-variant-numeric: tabular-nums`，否则右对齐会参差
103 
104违规形态：中文标题遇到英文长单词撑破卡片；价格列右对齐但数字宽度不一。
105 
106多语言场景额外要求：德语/俄语文本比中文长 40–80%，按钮宽度必须能容纳，或用 `min-width` 而非固定宽度。

110## F7 加载与占位
111 
112- 图片必须有 `width`/`height` 或 `aspect-ratio`，防止布局抖动（CLS）
113- 异步内容必须有骨架或占位，不能白屏后突然跳出
114- 字体加载：`font-display: swap`，且 fallback 字族的字宽要接近，否则切换时跳行

118## F8 语义与键盘
119 
120- 可点击元素用 `<button>` / `<a>`，不用 `<div onClick>`
121- 图标按钮必须有 `aria-label`
122- Tab 顺序与视觉顺序一致
123- 表单 `<label>` 与控件关联（`for`/`id` 或包裹）
124 
125这四条在 S5 里逐条检查，因为它们**看不出来但会坏**。而且 AI 生成页面几乎必犯第一条。

129## 与账本的关系
130 
131地板项在账本里以 `F1`–`F8` 编号出现在「依据」列，且「放弃」列写 `无，此为地板`。
132 
133这是账本里唯一允许放弃列为空的形态。除此之外任何空值都作废。
