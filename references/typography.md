# 排印与光学工艺

当文字、数字或控件本身就是主要材料时用。数值是试排起点，不是风格门槛；用目标字体、最终语言、真实长度和目标平台验收。

## 先决定字块，再决定字体名

取最长标题、普通正文、密集列表行、数字加单位、按钮各一条，在真实尺寸下试排。给标题、内容、辅助、数据分工；角色可以共用字体，但不能全靠颜色区分。字体没有实际加载或缺字回退时，先解决字面变化，再调间距。

- 标题看整体轮廓、语义断行及与主体的重量，不只看字号。桌面强制换行到窄屏可能碎成单字梯子；只保留有意义的断句，窄屏重新试排。
- 正文看连续数段形成的纹理、行长和段落间停顿。长篇文字可先试中文每行约24–36字、拉丁约45–75字符，再按实际阅读任务修正；窄详情栏不套正文行长。
- 辅助文字降低存在感靠位置、留白和层级共同完成，不靠读不清的浅灰。正文与标签先在100%尺寸看，再看整屏。
- 展示字体、单个衬线词、全大写、等宽标签不是天然对错。问这种字形在这里承担什么角色；不能为了“设计感”把业务说明都排成难读字样。

## 中文与混排不能沿用英文参数

先覆盖“收藏夹 / API 请求 / 2026年10月 / ¥1,280.00 / 重新连接”一组实际文本，观察字面、基线和字重是否突变。

1. 中文标题优先按词组组织行宽，避免为了硬凑英文式紧排而统一负字距。拉丁大标题的紧字距不继承到中文正文。
2. 用平台支持的禁则避免闭标点起行、开标点落行；Web 的 `line-break: strict`、适当的换行策略须在目标浏览器确认。不要用 `word-break: break-all` 破坏英语单词和编号来掩盖布局错误。
3. 中英字形高度不一致时先换成协调的字体组合与合适字号；不要给每个英文片段加随意的基线偏移。中文段落可从约1.6–1.8行高试起，紧凑控件另定，不把全文设成按钮行高。
4. 日期、型号、单位保持必要语义组；短数值单位可不换行，但长文件名/订单号仍须有完整查看路径。不要把整段塞进 nowrap。
5. 系统字体栈应含目标语言字体或合适系统回退。只下载一个拉丁字体并不解决中文排印；不为效果额外下载巨型字体包。

## 工作数据要精确，也要有呼吸

同类数值以小数位或右边界对齐；适用时用等宽数字，不把所有文字都改成等宽。金额、单位、趋势、缺值分别有语义；0不是缺值，未知不是0。用真实最长数值、负值和状态词试排，别只看漂亮的三位数。

把对象名、解释、状态、金额落在稳定列位上。优先保护对象识别与关键动作，再决定哪些低频信息转入详情；不要为了视觉干净删掉任务需要的字段。行内收紧、组间打开，行高随密度模式成套变化，命中区不能跟着缩没。

## 光学修正只在整体成立后做

检查同排圆形图标、文字与直边按钮的视觉中心，而不是只信几何盒子。图标笔画、字重、边界强弱在100%尺寸下应协调；小范围光学补偿可以存在，但先排除字体回退、错误 viewBox 和不一致行高。

截取同一对象的普通、焦点、选中和长内容四态复看。焦点与选中不同职，不能互相覆盖。动效测试中输入仍应立刻响应；数字更新不使整列晃动，长标题出现不让主按钮来回跳。

最后在窄屏、200%文字/浏览器缩放和减少动态下复查；原生用系统文字缩放与辅助功能，而不是拿Web截图代替。
