# 看图与审美判断

评审实际画面和操作，不评作者的解释。先隐藏版本名、设计自述和测试成绩，按目标视口看当前截图，再走真实任务。只有源码就明确没有完成视觉评审。

## 先问为什么值得欣赏，再找缺陷

用一轮完整画面作三遍观察：

1. **整体吸引力**：主落点、陪衬与安静区怎样构成画面？是否愿意继续看或操作？同尺度对照高水准参考，比较构图强度与完成度，不只比较谁更整齐。
2. **材料与工艺**：排印是否有节奏和合适的字块？图像/字样/数据是否经过认真呈现？边界、图标与控件是否形成一个整体？原尺寸检查，不从缩略图臆测精确字重。
3. **连续体验**：选择、进入、展开、反馈与返回是否延续前一状态的对象和身份？进入密集内页、长内容或窄屏后，美感是否仍成立？动效须实际操作观察，静态图不能证明触感。

每个正向判断指出“具体位置 → 关系 → 感受/使用后果”。例如“主要字样跨两栏，细小注释共用基线，形成有主次的展陈”，而非“很高级”；工作页也可以由列位、状态与细微对比共同成立，不要求必须有一个抢眼装饰。

## 分开判断使用底线和审美目标

**底线检查**：核心任务、内容真实性与完整性、可读可操作、键盘与可见焦点、控件语义、非纯颜色提示、文字缩放、减少动态；对比度与触达按平台标准。全部阻断项都列出，不受审美建议数量限制。

**正向审美检查**：

- **构图有意图**：视觉重量与疏密不是平均分配；重要内容在恰当位置，空白有作用。
- **表达有品位**：字体、色彩、材料与控件彼此支持，既非拼贴，也非什么都弱化；有适合这个产品的气质。
- **细节有完成度**：文字形态、裁切、边缘与状态经过推敲，没有优质主图配粗糙界面的断层。
- **体验有整体性**：吸引力延续到真实数据、内页与动作，不只停在封面。

这些是观察问题，不是固定风格阈值或可自动算分的公式。朴素界面也可能优秀；不是要求每项都新奇。对用户指定原稿，先按其视觉目标和还原度评价，不以评审者喜欢另一种风格为由判失败。

只符合底线，记为“可用，审美目标未证实”；有局部亮点但整体平庸，记为“表达未完成”，指出最大的关系差距；整体有吸引力且参考比较、细节与真实任务都支撑时，才给出执行者认为方向成立的理由。没有用户确认，不写用户认可；缺读图、参考或运行证据时说明缺哪一种。

## 按根因纠偏，不无止境微调

| 观察 | 优先改哪里 | 不要拿什么替代 |
|---|---|---|
| 任务清楚，界面整齐却没有吸引力 | 视觉主张、主次张力、排印或核心材料，做一次成套变化 | 追加阴影、圆角或“高级感”文案 |
| 标题/封面精彩，实际内容平庸 | 对象表达、密度节奏、控件与内容的共同语法 | 再放大首页标题 |
| 参考很好，结果不像 | 区域比例、字块、素材裁切、表面与状态还原 | 擅自降低参考目标 |
| 局部精彩但拼贴感强 | 保留一个主导语法，让其它元素归队 | 再加一种有特色的风格 |
| 漂亮但用户不好用 | 任务链、可见信息、状态与平台操作 | 把内容删掉或藏起来 |
| 整体成立、局部别扭 | 光学对齐、字重、边界、间距或反馈 | 为展示创造力重做全站 |

审美改进优先列最重要的两三处，给出改变层级与预期画面结果；保留真正成立的优点及其原因。用户反复说不好看时重审方向，不继续替现稿辩护。

## 比较候选与防止自证

同一内容、视口、状态比较候选，不故意把其中一版做坏；隐藏作者解释和版本名称。分别看吸引力、气质适配、工艺与任务，不让一张好图掩盖功能损失，也不让功能全绿替平庸加分。桌面、窄屏与跨状态分别下结论，再说明取舍；桌面胜出不能掩盖移动端信息后移或对象身份丢失。

有独立读图能力时，给独立评审者任务、明确约束、参考与当前截图；先请其描述实际看到的美感与最大差距，再给设计卡检查兑现情况。评审者若不能读图、只是复述文案，其结论不算视觉复核。同模型一致也不是跨模型效果或用户认可。

## 独立看图的交接

把下面的短委托与实际图片交给新的评审上下文。不转发作者的分析、版本优劣、期望赢家或测试分数；文件名也不要叫 improved / winner。没有独立评审工具时自己按同样顺序看图，标明非独立。

```text
任务：用户要对什么对象完成什么动作；保留哪些事实与能力。
图片：同视口的完整关键屏、密集/展开状态、窄屏；有指定原稿则一并给出。
请先读图，不读作者说明，不写代码。
1. 描述第一眼实际落点与视线路径，以及一处值得保留的关系。
2. 指出最拖累画面的最多两处：位置 → 根因 → 一次具体改动 → 预期可见结果。
3. 分别判断吸引力、产品适配、细节和跨状态完整性；允许互有优势、打平或都不满意。
4. 给下一步：保留方向 / 改局部关系 / 重做构图或材料 / 证据不足。
不猜用户喜好；不从静态图推断交互通过；没有直接看图就声明不能视觉判断。
```

收到意见后再对照设计卡：评审抓到了主张却不买账，重审方向；根本没看出主张，先查尺度、字块或材料是否丢失；只是风格偏好不同，不抹掉用户已认可方向。独立意见是纠偏证据，不是自动权威。

## 将批评变成一次可检查的改动

不要转述“再高级一点”给实现者。给目标组件和保留项，例如：“详情标题与总价都用同一粗度抢焦点；保留完整金额和操作，将解释并入票据下半区、拉开标题/说明字阶；重拍相同订单，检查是否一眼先见诊断再见行动。”具体尺寸由当前画面决定，不能从另一项目照抄。

每轮只改最影响整体的关系及其必要配套，保留修改前截图；修后与同视口、同状态的旧帧比较。结果不支持预期就撤回这一实验或换根因，不把每次改动都叫进步。缺失字段、假数据、不可达操作和安全问题单列全部处理，不受两条审美意见限制。

选定方向后的复查预算遵循主入口。预算结束而目标未达，明确报告未达与原因；纯评审只交判断与建议，实施任务在授权范围修正并复看。交付当前入口、截图和限制，功能、审美判断、偏好三项分开，不报虚构美感分数。
