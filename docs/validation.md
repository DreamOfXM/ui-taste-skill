## 独立行为演练

按 skill-creator 的 Independent Forward-Testing，由未继承设计讨论的独立 agent 只读 skill 及按需引用，给出下一步动作、追问需求和交付所需证据。输入没有页面，以下结果仅说明对指令的理解。

| 请求 | 观察到的决策 |
|---|---|
| 中文订单后台改高级，保留 100 行和红黄绿告警 | 从任务、列分组、密度和层级改进；保留项目字体/白底/操作色与告警，不强行套风格阈值；要求真实操作与长内容证据 |
| 只对齐保存按钮和输入框 | 最小局部调整，不做多版，不改无关部分，检查相关宽度和保存反馈 |
| 紫色亲子 App，两个方向，选后再实现 | 保留紫色品牌，比较同内容的两个完整方向；等待用户选择，不将推荐写成认可 |
| 扫描全通过但看着乱，只评审 | 回到真实画面和任务排序问题，不以全绿替代视觉判断，不修改代码 |

演练指出四处潜在歧义：选稿前候选原型与正式实现的边界；方向探索缺少直接方法链接；方向与项目约定记录的分工；纯评审和实施交付措辞。已逐项修正，独立复核确认四处均已解决。未把这些潜在歧义伪称为已发生的产品故障。
