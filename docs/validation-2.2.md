最终执行：17 项 Python 测试全部通过（11 项安装回归、6 项包完整性）；浏览器验证脚本与 HTML 中的 1 段内嵌 JavaScript 语法检查通过；`git diff --check` 通过。包测试确认当前 HTML 与八张截图均符合报告中的 SHA-256，执行文档的相对链接可解析。

本机使用 Python 3.9.6 与 Qoder 随附 Node（启动时设置 `ELECTRON_RUN_AS_NODE=1`），没有安装新依赖。其他机器可使用自己的 Python 和 Node 执行下列命令。

```sh
python3 -B -m unittest discover -s tests -v
node --check scripts/verify-app-craft.cjs
node scripts/verify-app-craft.cjs
```

Python 检查只使用标准库，安装用例只操作临时目录。包检查核对 frontmatter、描述、版本、入口长度、执行文档相对链接、未解决标记、静态重复 ID、外部资源，以及当前源码和截图哈希。JavaScript 语法检查另外使用 `vm.Script` 解析 HTML 内嵌脚本，不在 Node 中执行 DOM 代码。

浏览器检查要求已安装 Chrome/Chromium，可用 `CHROME_BIN` 指定路径；缺环境应报告未运行，不自动安装。修改 HTML 后先重跑浏览器取证，再跑包检查；图像哈希一致不代表看过新图或审美已获认可。
