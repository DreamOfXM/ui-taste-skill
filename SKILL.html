Faithfully reproduces a provided mockup; local polish touches only the affected area. Not for backend logic or non-visual bug fixes.

7# UI Taste
8 
9## 定位
10 
11把一屏当成一件完整作品来做，不是逐条满足规则。
12 
13skill 管两件事：**保底**（不残、不丑、内容真实、节奏统一、能操作）和**提高上限的概率**（靠正面原则 + 统一底子 + 范例）。它不承诺"保证好"——好是构图、张力、材料、记忆点这些关系属性，清单数不出来，只能渲染出来看、跟范例并排比、最后让用户挑。
14 
15**整体先于细节，连贯先于合规。** 先把一屏的主次、节奏、材料做连贯，再精修细节。**不在旧稿上打补丁**——补丁会留下结构疤痕（被放大的产品名、被拉伸的行距、忽大忽小的块间距），越补越散。要改就重做那一屏。
16 
17## 七条正面原则（先做这些，不是先躲那些）
18 
191. **先定界面给谁、他要判断什么、完成什么。** 对象随产品变：工具是使用者，内容是读者，商品页才是买家——别把买家当成所有界面的默认对象。首屏只突出一个最重要的事实或结果：能核对的数字、一个结果或画面、一个能立刻做的动作、对象身份。立场句、免责声明、品类名是支撑，不是主角。
20 
212. **标题是一句对看的人有意义的话，且是首屏最大的字。** 说好处或处境：「换一种豆子，不用赌上一个月」「看清钱花在哪，账单不出这台机器」。产品名和品类是小字眉题，不是巨字。判法：把标题单独抄出来问"这在跟谁、说什么好处或处境"，答得出才算。
22 
233. **首屏最大的图是产品对象本身，画到有材质、有体积。** 受光面、投影、透光、织物纹理；对象浮在地面上，标注可环绕。推广页首屏不放要读坐标轴/刻度/图例的分析图表，也不放滑块/开关/导出面板（页面本身就是工作台时例外）。
24 
254. **一套间距/字号刻度贯穿全页，节奏统一。** 间距只用 4/8/12/16/24/32/48/64/96；字号按用途取档（见 `tokens/scale.md`）。**左栏自然高度、同级同距**；右栏对象明显更高时，让左栏整体垂直居中（grid `align-items:center`），内部间距仍统一，不要顶部对齐留下左下一块空。不要用 space-between 把左栏拉到跟右栏一样高，那会让块间距忽大忽小。空了先问"这块该不该存在"，不是"怎么填满"。
26 
275. **文案是写给看的人的话，关键事实一眼可扫。** 用「你」不用「用户」；首屏有一句接住来路的话（点出处境或顾虑），再加一句短 lede 说好处。关键事实不要埋进两三段密句子——密段落读不动。**突出的手段随内容选**：几条并列短事实用一行胶囊/标签（如「本机 + 你的 iCloud」「不联网也能记」）；一个核心数字放大并带比较对象；一组可比数据用小表或事实带；变色、加粗同样可以。胶囊只是其中一种，不是每页必用。句子负责语气与来路，承载形式负责让事实可核对、扫得快。
28 
296. **颜色从产品本身来，承诺一个主色家族。** 从产品界面/材质采样定主色，一个强调色相（多级改明度不改色相）+ 语义色 + 冷暖中性色分层。主色当文字色必须实测对比度。**底色排最后**——先定布局与文字，再定色。
30 
317. **整体做连贯，再精修；要改就重做那一屏。** 先看主次有没有力量、字块讲不讲究、材料值不值得看、操作跟内容是不是同一件作品。只是整齐就不加装饰掩盖，回到结构修。
32 
33## 统一底子
34 
35- **间距 / 字号 / 字重 / 圆角 / 阴影 / 动效**：`tokens/scale.md`。把"随手值"变成"体系值"的格子，全页共用一套，节奏才统一。
36- **文案口吻**：第 2、5 条是底线；更多写法与边界见 `references/content-architecture.md`（选读）。
37- **品类默认家族**（选读）：判品类后从 `registers/category-prototypes.md` 取该类底面/字体/字号/曲率/密度默认；排印整套餐从 `registers/type-recipes.md`，材质整套餐从 `registers/surface-recipes.md`。**一页内部不混搭。**
38 
39## 范例（借关系，不抄配色）
40 
41`references/taste-gallery.md` 有两张用户亲手选中的首屏。动笔前**实际打开至少一张**看图，借**一条**主关系：地面托住对象 / 对象浮置有体积 / 标题层级 / 同类事实成一条带 / 首屏完整。禁外链时这里是唯一能看的依据，不许用文字想象代替看图。
42 
43## 短清单兜底（地板，渲染后逐条看）
44 
45全过只证明"不坏"，证明不了"好"；好靠并排比和用户挑。
46 
47- 核心任务链实际走通；内容真实完整，无占位、无编造指标。
48- 没看过 brief 的人能一眼复述：这是什么 / 最关键的事实或结果 / 多少钱或怎么买。
49- 标题是对看的人说的话且是首屏最大字；产品名/品类是小字。
50- 文案对象对：工具对使用者、内容对读者、商品页对买家；不把买家话套到非商品界面。
51- 首屏最大的图是对象不是图表/控件；对象有体积。
52- 节奏统一：同级同距，左栏不拉伸填充。
53- 首屏不以死白收尾：下一节的标题或首行要进入首屏；首屏底部空一大块即缺陷。
54- 顶栏链接宁少勿挤：删掉与按钮重复的入口，链接之间留足间距。
55- 首屏关键事实一眼可扫（胶囊行 / 放大数字 / 小表 / 事实带，随内容选）；hero 不堆两三段密正文。
56- 首屏内容区底边用一条数据带或一行关键事实锚住，不让左栏下方松一大块留空。
57- 首屏两栏几何：内容区够宽，关键事实不被挤换行；对象画大、贴近外缘，不缩在小框里留大边距；左栏对高对象垂直居中。
58- 侧栏/右上文案：一句透气的话 + 一眼可扫的关键事实，不把尺寸/重量/数量堆进一段密句。
59- 对比度达标（实测）；无溢出、裁切、遮挡、错位。
60- 状态齐（hover/焦点/选中/空/错/加载）；键盘可达，焦点可见。
61- 过程语言不进产物（方向甲乙/关键屏/回读/账本/破例/练习用虚构 等一律删）。
62- 开放设计含 1 版自由版：子代理产出（不加载技能、只传 brief），主 agent 只查地板并留派发证据；同等参选，它赢就交它。
63- 桌面与移动（真 390）都看过，无运行时错误。
64 
65## 分流
66 
67| 任务 | 做法 |
68|---|---|
69| 给了原稿 / 已认可方向 | 原稿即规格，单稿忠实深化，沿用其字级/留白/材料；只记偏差 |
70| 已有上线页面 | 先整页打开评级；成立则校准（保留身份与最好关系，只修真实缺陷），不成立才开放重做 |
71| 局部精修 | 只改受影响处，不借机翻新整页 |
72| 开放新设计 / 整体重做 | 七条原则 + 统一底子 + 范例，先把一屏做连贯；给 6–7 版明显不同的关键屏供挑选：5–6 版按原则（构图/材料/对象表达至少两轴不同），另加 1 版自由版——派子代理产出（不加载本技能、只传 brief），见下节；挑定再展开整页 |
73 
74## 自由版派发与检查
75 
76- **派子代理，不是子 skill。** 自由版由一个新子代理产出：不加载本技能、不继承主会话的设计推理。主 agent 在主会话里自己画的那版上下文已被污染，不算自由版。
77- **只传 brief。** 派发提示只给：页面任务、受众、必须保留的事实、交付规格（关键屏 HTML、同视口同内容）。不传七条原则、刻度、品类默认、范例，也不传主 agent 的方向推理或风格暗示。
78- **回来只查地板。** 主 agent 只查内容真实、能用、无溢出裁切；不得按技能「修好看」再参选。确需修地板问题时，记录修了什么。
79- **留派发证据。** 交付说明里记子代理标识、派发提示摘录、子代理「未加载 ui-taste-skill」的回报；缺证据的自由版按未产出处理。
80- **没有子代理能力就如实说。** 环境派不出子代理时，声明自由版缺失，不用主会话版冒充。

90**默认不跑**探针、六列账本、回读门、逐版闸门——那些是可选深查，不是每次的必经流程。省下的回合花在画面上：**流程赢不了画面，画面才赢画面。**

92## 诚实契约
93 
94保底可靠，上限靠范例与并排对照提高概率，不承诺保证好。优劣归用户：同视口、匿名打乱、并排二选一，问"你愿意装哪个"，不问分数。生产者自评不能单独当审美结论。开放设计固定留 1 版自由版（子代理产出、不套本技能规范）：规范是启发式不是上限，自由版赢就照交。
