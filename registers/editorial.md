# register: editorial（纸与字）

把界面当成一份印出来的东西。层级全靠字号反差和栏宽，不靠色块。

## 标志手法

- **R1** 标题与正文的字号比 ≥3:1（如 38 / 12.5）。这个反差是这一调性的骨架，弱于 2.5:1 就不成立。
- **R2** 单栏或双栏，栏宽 60–72 字符（中文约 30–36 字）。栏宽是硬约束，不是留白的美化。
- **R3** 用细线（1px，低不透明度）和留白做分隔，不用卡片、不用阴影。

## 禁忌

- 彩色大面积背景（破坏纸感）
- 圆角 >6px（纸没有圆角）
- 装饰性插画和 emoji（除了正文里的标点）

## 数值起点

- 底 `#FBFAF7`（暖白），墨 `#2B2A26`，次要 `#6B6F76`
- 强调色只用**小面积落点**，不铺大色块；落点数仍须 ≥3（关键数字、当前选中项、链接或标签各一处），否则整页会退成灰稿（`references/critique.md` 第十一问）。当文字色时需 7:1 以上
- 圆角仅 0 / 2
- 行高 1.65（比常规更高，纸媒习惯）

## 适合

长文阅读、产品文档、观点型落地页、出版物、需要"可信"而非"亲切"的场景。

## 不适合

高密度工具、需要强调可点击性的表单、儿童/娱乐类、移动端单手操作场景（栏宽约束难满足）。
