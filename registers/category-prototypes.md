# 品类原型库（category prototypes）

S1 必读，G0 方向门的**第一层**。**先判品类，再定底面、版式与文案组织。**

## 为什么第一层是品类，不是「风格」

0.2.5 把表面做成了六套抽象配方（暗夜仪表 / 冷白图纸 / 暖纸书卷 / 清透柔性 / 纯白临床 / 品牌高饱和），并写了一句「冲突时以受众×场合为准，**不以产品品类为准**」。这句话是错的。

用户原话：

> 「颜色你不能乱定，就是背景色，你要根据我们这个产品是什么产品，比如说它是科技产品，或者说是电商类的，或者说是美妆类的或者说是其他的母婴类的等等不同品类，它的背景色是不一样的。或者说是小红书类的……所以你在推荐的时候不应该按照统一的乱推荐，你不能乱推荐。」

三个理由，按重要性排：

1. **品类是用户 1 秒能回答的客观事实**，「清新风 / 科技感 / 高级感」不是。问品类不会卡住对话，问风格会。
2. **品类有统计规律，风格没有。** 美妆页面 `border-radius: 0` 不是审美偏好，是行业共识（Glossier 全站 0 圆角、Rare Beauty 0 圆角、花西子 0 圆角）；母婴页面按钮圆角 ≥12px（BabyBjörn 32px、Pampers 12px）。这些是可实测的分布，不是形容词。
3. **品类决定文案组织。** 电商首屏必须先给价格和商品，母婴首屏必须先给安全认证，SaaS 首屏必须先给能力断言。同一个「好标题」在这三个品类里长度、句式、落点全不同——这是 0.2.5 完全没有覆盖的一层。

### 但品类不是刻板印象

同一个品类内部一定有分化，所以**每类给主型 + 次型两套完整规格**，不给一个色值。开发工具里 Linear 近黑、Vercel 近白；电商里淘宝纯白密排、Shopify 纯黑大标题；美妆里 Glossier 纯白、花西子深底影像。**说「科技产品就用黑底」是另一种统一模板。**

判据只有一条：**每条取值必须挂到该品类 ≥1 个真实站的 R2 实测值上**。挂不上的写 R0，并标明是假设。

## 怎么用（三步，不许跳）

### 第一步：定品类

从下表选一个，选不出就选「主品类 + 副品类」（例：DiskWise = C1 开发工具 主 + C9 消费电子 副）。**品类不定，不许进 S2。**

| 代号 | 品类 | 典型对象 | 用户会怎么描述 |
|---|---|---|---|
| **C1** | 开发工具 / 技术 SaaS | Linear、Vercel、监控、CLI、API 产品 | 「给程序员用的」「B 端工具」 |
| **C2** | 电商与零售 | 平台、店铺、大促页、商品详情 | 「卖货的」「电商」 |
| **C3** | 服饰 / 生活方式 DTC | 鞋服、家居、日用品品牌官网 | 「品牌官网」「卖衣服的」 |
| **C4** | 美妆护肤 | 精华、彩妆、香水、个护 | 「美妆」「护肤」 |
| **C5** | 母婴 | 纸尿裤、背带、辅食、玩具 | 「母婴」「宝妈」 |
| **C6** | 内容社区 / 内容电商 | 小红书类、B 站类、灵感站、笔记流 | 「小红书那种」「社区」 |
| **C7** | 金融科技 / 支付 | 支付、企业账户、保险、理财 | 「金融」「支付」 |
| **C8** | 食品饮料 | 饮料、零食、乳品、酒 | 「食品」「饮料」 |
| **C9** | 消费电子 / 硬件 | 手机、耳机、音箱、硬件产品页 | 「科技产品」「硬件」 |

### 第二步：取该品类的默认家族

默认家族 = 底面 + 卡面 + 墨色 + 字体 + 字号 + 行距 + 按钮 + 曲率 + 线宽 + 版心 + 密度 + 首屏图文比，**十二项一起给**。这就是交给用户的候选卡，不是让模型自己挑的菜单。

### 第三步：只在「允许偏离」里改

每类末尾列了可偏离项和代价。改一项记一条账本；**改两项以上就已不是在用这个品类，而是在造一个新品类，必须回 G0 重新确认。**

## 九品类底色一览（先看这一张，确认「不一样」）

| 品类 | 主型底面 | 主型亮度 | 次型底面 | 次型亮度 |
|---|---|---|---|---|
| C1 开发工具 | `#08090A` | 0.00 | `#FAFAFA` | 0.96 |
| C2 电商零售 | `#FFFFFF` | 1.00 | `#000000` | 0.00 |
| C3 服饰 DTC | `#ECE9E2` | 0.82 | `#FFFFFF` | 1.00 |
| C4 美妆护肤 | `#FFFFFF` | 1.00 | `#FDFBF8` | 0.97 |
| C5 母婴 | `#F8F5F1` | 0.92 | `#FFFFFF` | 1.00 |
| C6 内容社区 | `#F1F2F3` | 0.89 | `#FFFFFF` | 1.00 |
| C7 金融科技 | `#FFFFFF` | 1.00 | `#F6F7F9` | 0.94 |
| C8 食品饮料 | `#000000` | 0.00 | `#FFFFFF` | 1.00 |
| C9 消费电子 | `#FFFFFF` | 1.00 | `#000000` | 0.00 |

九个品类里 **5 类主型是白**。这不是「又统一了」——白与白之间的差别在**曲率、字重、密度、按钮形状、首屏图文比**：

| 品类（主型） | 按钮圆角 | 按钮高 | 标题字重 | 正文 | 首屏图文比 | 实测来源 |
|---|---|---|---|---|---|---|
| C1 开发工具（浅色次型） | 6px | 32 | 400 | 16 / 1.5 | 字为主（1052 字 / 0 图） | vercel.com |
| C2 电商（平台型） | 8–12px | 40 | 700 | 12 / 1.5 | 图为主（788 字 / 7 图） | taobao.com |
| C4 美妆 | **0** | 36–40 | 400 | 16 / 1.15 | 图为主（467 字 / 11 图） | glossier / rarebeauty |
| C5 母婴（次型） | 12px | 48 | 600–700 | 16 / 1.6 | 折中（96 字 / 1 图） | pampers.com.cn |
| C6 内容社区 | 6px | 28 | 400 | 16 / — | 图为主（312 字 / 23 图） | bilibili.com |
| C7 金融（主型） | 4–6px | 40 | 400–500 | 16 / 1.5 | 折中（178 字 / 1 图） | stripe.com |
| C9 消费电子 | **pill** | 44 | 400 | 17 / 1.47 | 图为主（3392 字 / 2 图，跨屏） | apple.com |

**结论：底色只是第一眼，品类识别真正靠的是「曲率 + 字重 + 密度 + 图文比」四件事。** 只换底色不换这四项，仍然通用模板。

## C1 · 开发工具 / 技术 SaaS

### 主型 C1a：深色仪表

| 维度 | 取值 | 证据 |
|---|---|---|
| 底面 | `#08090A`（近黑，非纯黑） | R2 linear.app `rgb(8,9,10)` lum 0.003 |
| 卡面 | 底面 +5–7% 白 `rgba(255,255,255,.055)`；**不用白卡片** | R2 同站 |
| 墨色 | 正文 `#E8EAF0` 一类低饱和浅灰，不用 `#FFF` | R2 |
| 字体族 | 西文几何 grotesk（Inter / Geist）；中文 `PingFang SC`；数字 `tabular-nums` | R2 `Inter Variable` / `GeistSans` |
| 字号 | H1 56–64，正文 16，标签 12–13，注释 11 | R2 64 / 16 |
| 行距 | H1 **1.00–1.08**，正文 1.50，标签 1.35 | R2 1.0 / 1.5 |
| 字距 | H1 **-0.02 ~ -0.03em**（大字负字距是这一类最强的指纹） | R2 `-1.408px @64` = -0.022em；Vercel -3.84px @64 = -0.06em |
| 按钮 | 高 32–40，圆角 6–8，字重 500–600，实心品牌色；次按钮 1px 描边 | R2 radius 8×17 / 6×39 |
| 曲率 | 6–8px 统一；允许一处 pill 作强调 | R2 |
| 线 | 1px `rgba(255,255,255,.08–.12)` 承担分块，**几乎不用阴影**（shadowShare ≤0.02） | R2 |
| 版心 | 1200–1280；文本列 ≤640 | R2 1282 / 1416 |
| 密度 | 中高：首屏 ≥250 字 + 一张真实界面 | R2 413 字 / 1 图 |
| 首屏 | 左文右界面，或居中文字 + 下方界面；**必须有产品真实界面** | R2 |

**文案组织（栏目顺序）**

1. 首屏：能力断言（一句，≤18 字，动宾结构）+ 一行机制（怎么做到的，≤40 字）+ 主 CTA「开始 / 安装」+ 次 CTA「文档 / GitHub」+ 真实界面截图或可交互 demo
2. 「它替掉了什么」：前后对照或与 incumbent 逐项对比（这一栏是这类页面的信任核心）
3. 能力清单 3–4 条：每条 = 动词短语标题 + 一句证据（数字、命令、截图）
4. 集成 / 兼容：真实 logo + 真实数量，不写「支持众多平台」
5. 定价：表格，标清免费额度与限制
6. FAQ / 反对处理：安全、迁移成本、离线、退款
7. 页脚：版本号、changelog、GitHub、许可证

**禁忌**：大圆角 + 彩色渐变（变成消费级工具）；「赋能 / 一站式 / 重新定义」空话；hero 没有真实界面；正文用衬线。

### 次型 C1b：浅色平台

| 维度 | 与主型的差异 | 证据 |
|---|---|---|
| 底面 | `#FAFAFA` 或 `#FFFFFF` | R2 vercel.com `rgb(250,250,250)` |
| 曲率 | 6px 统一，**零阴影** | R2 radius 6×39、shadowShare 0.02 |
| 字距 | 负更多（-0.04~-0.06em），H1 64/400 而非 700 | R2 `-3.84px @64` |
| 线 | 1px `#E5E5E5` 级浅线，或完全无线靠留白 | R2 |

**什么时候选次型**：产品界面本身是浅色、受众包含非工程师、需要投屏/打印。**代价**：与「暗色产品截图」的接缝问题反过来了——浅底页面配深色产品截图会显得截图是黑的补丁。

## C2 · 电商与零售

### 主型 C2a：平台货架

| 维度 | 取值 | 证据 |
|---|---|---|
| 底面 | `#FFFFFF` 纯白（不用暖白：商品图色准优先） | R2 taobao.com `rgb(255,255,255)` |
| 卡面 | 白卡片 + 8–12px 圆角；促销标签用高饱和红/橙 | R2 radius 12×4、18×2、8×2 |
| 墨色 | `#111` / `#666` / `#999` 三级；价格用主色或红 | R2 |
| 字体族 | 系统无衬线（`PingFang SC` / `system-ui`） | R2 |
| 字号 | **正文 12–14**（比任何其他品类都小）；价格 16–22 加粗；标题 12–14 | R2 12px |
| 行距 | 1.5（密排是功能，不是失误） | R2 1.5 |
| 按钮 | 高 32–40，圆角 8–12，字重 400–600，橙/红实心 | R2 圆角 8 / 12 |
| 曲率 | 8–12px | R2 |
| 线 | 1px `#EEE` 分隔；**卡片靠留白与线，不靠阴影** | R2 1px×2 |
| 版心 | 1200–1440，栅格 4–6 列 | R2 容器 1760（超宽）、内容 624 |
| 密度 | **极高**：首屏 5–8 张商品图 + ≥700 字 | R2 788 字 / 7 图 |
| 首屏 | 搜索栏 + 分类 + 促销位 + 商品栅格；**首屏就要有价格** | R2 |

**文案组织**

1. 顶栏：搜索框（宽度占比 ≥30%）+ 分类 + 购物车 + 登录
2. 首屏：1 主促销位 + 4–6 次位，每块必须有价格或折扣
3. 商品栅格：图 → 名称（≤2 行）→ 价格（最大字号）→ 销量/评分 → 店铺
4. 信任条：发货时效、退货、正品保障（一行四个图标 + 短句）
5. 频道入口：按品类/场景分栏
6. 页脚：客服、帮助中心、备案号、支付方式图标

**禁忌**：大留白（密度就是功能，留白=少商品=少成交）；把价格藏到详情页；用 96px 标题挤掉商品位；用衬线标题。

### 次型 C2b：品牌大促页

| 维度 | 与主型的差异 | 证据 |
|---|---|---|
| 底面 | `#000000` 满幅影像/视频 | R2 shopify.com `rgb(0,0,0)` |
| 字号 | H1 **72–96px，字重 300**（细！），行距 1.05–1.10 | R2 96 / 300 / 1.08 |
| 按钮 | pill（`9999px`），高 44–56，纯白实心 + 白描边次按钮 | R2 radius 9999 / 高 44–56 |
| 线 | 2px（比其他品类粗一倍） | R2 2px |
| 版心 | 1260，居中 | R2 1260 |

**什么时候选次型**：发布会、大促、campaign 落地页。**代价**：可扫读差，商品信息必须另开一屏。

## C3 · 服饰 / 生活方式 DTC

### 主型 C3a：材质米灰

| 维度 | 取值 | 证据 |
|---|---|---|
| 底面 | `#ECE9E2`（米灰，暖但低饱和；**不是奶油黄**） | R2 allbirds.com `rgb(236,233,226)` lum 0.816 |
| 卡面 | 同底或 `#F5F3EE`，**无边框无阴影**，靠图分块 | R2 shadowShare 0 |
| 墨色 | `#212121`（近黑但不纯黑） | R2 按钮底 `rgb(33,33,33)` |
| 字体族 | 几何无衬线（Geograph / Avenir Next 一类） | R2 `Geograph` |
| 字号 | H1 由影像承担（文字标题仅 24px）；章节标题 32–40；正文 16 | R2 h1 24（主标题在图内） |
| 行距 | 1.33 / 1.50 | R2 |
| 字距 | **+0.02~0.04em**（唯一正字距的品类，显得松弛） | R2 `0.6px @24` = +0.025em |
| 按钮 | pill，高 33–40，字重 500，深色实心 | R2 radius full / 高 33 / w500 |
| 曲率 | 16px 与 pill 并存 | R2 full×21 / 16×24 |
| 线 | 1px 浅线（`#D8D3C9`），用得比 C1 多 | R2 1px×21 |
| 版心 | 1360–1420（接近满宽，影像要满） | R2 1420 |
| 密度 | 低：首屏 ≤450 字 + 8–9 张图 | R2 456 字 / 9 图 |
| 首屏 | 满幅产品影像 + 一句话（≤8 字）+ 一个 pill 按钮 | R2 |

**文案组织**

1. 首屏：满幅影像 + 一句短语（≤8 字，不解释产品）+ pill CTA
2. 材质 / 工艺三段：每段一张细节特写 + 2 行说明（可溯源：羊毛来自哪、几道工序）
3. 尺码与适配：真实尺码表 + 「偏大/偏小」提示（这一栏的转化价值高于任何形容词）
4. 用户实拍（UGC）：≥6 张真实买家图，不用棚拍
5. 退换与保养：具体天数、具体方式
6. 邮件/短信订阅（首单激励）

**禁忌**：纯白底（会掉进快时尚白牌）；高饱和撞色；没有实物细节图；用「极致舒适」这类不可验证的形容词代替材质说明。

### 次型 C3b：纯白画廊

底面 `#FFFFFF`、曲率 0、字距 0、标题用衬线。**适用**：高单价、设计师品牌、需要「画廊」感的系列页。**代价**：与 C4 美妆撞脸，品类辨识度下降。

## C4 · 美妆护肤

### 主型 C4a：纯白画廊

| 维度 | 取值 | 证据 |
|---|---|---|
| 底面 | `#FFFFFF` 纯白（不是暖白） | R2 glossier.com `rgb(255,255,255)` |
| 卡面 | **无卡面**：无边框、无圆角、无阴影，商品直接落在白上 | R2 radius 全 0、shadow 0 |
| 墨色 | `#000` / `#333`；品牌色只用在一处（按钮或标签） | R2 |
| 字体族 | 无衬线 400 字重为主；**标题可用衬线**（Ogg / Songti SC） | R2 rarebeauty `Ogg Regular` |
| 字号 | H1 20–48（**比 SaaS 小得多**，视觉重量交给图）；产品名 28–36；正文 14–16 | R2 glossier h1 20；rare h1 48 |
| 行距 | 1.15–1.40（偏紧，像杂志图注） | R2 1.15 / 1.4 |
| 按钮 | 高 36–40，**圆角 0**，字号 10–14，字重 400，实心深色或品牌酒红 | R2 r0 / 高 36 / 10px |
| 曲率 | **0**（这一类最强的指纹，全站 0 圆角） | R2 radius 全 0 |
| 线 | 1px 极细；大量用留白而非线 | R2 1px×1–13 |
| 版心 | 1280–1360；产品文案列 ≤520 | R2 1332 |
| 密度 | 低：首屏 ≤500 字 + ≥8 张大图 | R2 467 字 / 11 图 |
| 首屏 | 满幅产品/肌肤影像 + 产品名 + 一句功效（≤12 字） | R2 |

**文案组织**

1. 首屏：影像 + 产品名 + 一句功效（≤12 字，动词开头）
2. 成分 / 配方：3 个关键成分 + 浓度（真实数字），不用「珍稀植萃」代替
3. 质地与使用：特写图 + 使用前后（合规前提下）
4. 媒体 / 达人引用：带出处与日期，不用「众多达人推荐」
5. 规格与套装：毫升数、单价对比
6. 肤质提示 / 过敏警示（合规必备，不放下一步）

**禁忌**：圆角（美妆全行业 r0，一圆就变成工具类）；粗字重标题（400 为主，700 会像促销页）；科技蓝；纯功能罗列（这个品类卖的是欲望与身份）。

**适用**：东方美学、香氛、礼盒、文化叙事。**代价**：可扫读差，商品参数必须另起一屏；深底对产品图色准要求高。

## C5 · 母婴

### 主型 C5a：暖白圆角

| 维度 | 取值 | 证据 |
|---|---|---|
| 底面 | `#F8F5F1`（暖白，比 C4 暖、比 C3 浅） | R2 babybjorn.com `rgb(248,245,241)` lum 0.916 |

## 跨品类地板（不参与取舍，任何品类都必须过）

1. **对比度**：正文 ≥4.5:1，大字 ≥3:1。见 `craft-floor.md F1` 的实测脚本。深底品类最容易翻车的是「低饱和浅灰正文」。
2. **点击区**：≥44×44（移动端）。C6 的 28px 高按钮只允许出现在桌面端的信息流 chip 上。
3. **中文行宽**：正文 30–40 字/行。C9 的 996 版心用于短句，长文段落必须收到 640–720。
4. **一页一套**：底面/卡面/墨色/线/曲率必须同族。混两种明暗系统 = 白补丁。

---

## 判品类时的三个坑

1. **按公司规模判，不按产品判**：一个卖软件的电商（Shopify）是 C2 不是 C1；一个做硬件的 SaaS（Tesla 的充电网络后台）是 C1 不是 C9。**判据是「这页要让用户做什么」**，不是「公司属于哪个行业」。
2. **一个页面只能有一个品类**：品牌官网首页（C3）和商品详情页（C2）可以不同品类，但**同一页不许混**。混了就是两套曲率、两套字重、两套密度——用户看到的正是「通用模板」。
3. **「科技感」不是品类**：它是对 C1/C9 的形容词化。用户说「我要科技感」时，先问「是给工程师用的工具（C1），还是卖硬件（C9）」——这两个答案的底面、按钮、版心完全不同。

## 证据与边界

- **R2 实测**：linear.app、vercel.com、shopify.com、taobao.com、allbirds.com、glossier.com、rarebeauty.com、huaxizi.com、babybjorn.com、pampers.com.cn、bilibili.com、dewu.com、dribbble.com、zhihu.com、stripe.com、mercury.com、liquiddeath.com、oatly.com、apple.com、bang-olufsen.com。原始数据在 `diskwise-023/refs/surface-batch1–4.json`，工具 `scripts/probe-surface.mjs`。
- **取样偏差必须说明**：这是 20 个站的横截面，不是行业普查。C2 的「12px 正文」来自淘宝一个国家站；C4 的「0 圆角」来自 3 个站；C5 只有 2 个站。样本量小的结论只能当**默认起点**，不能当定律。
- **无效样本已剔除**：aesop.com（Cloudflare 拦截页）、xiaohongshu.com（风控 error_code 300012）、sony.com（Access Denied）、babycare.cn（无法访问）、teenage.engineering（body 无背景，取不到值）。这些**没有**被当作证据使用。
- **未覆盖的品类**：教育、医疗、政务、B2B 制造、旅游、汽车、房产、招聘。这些没有实测，不许凭印象套用上表任何一类。
- 底色是 1440×1000 视口、`prefers-color-scheme: light` 下取的 `body` 计算值，**不含**首屏大面积图片/视频覆盖。所以「深色」可能是影像而非 CSS 底色——引用时要注明。
