# register: brutalist（原始）

把材料的原始状态露出来。硬边、无过渡、单色块、明确的字。

## 标志手法

- **R1** 1px 或 2px 硬边框，颜色是墨色本身（不是灰），边框承担全部结构。
- **R2** 单一高饱和色块，面积可以很大（30%+），但只有一个色相。
- **R3** 字体用系统默认或极常见的无衬线，字号跳跃（48 → 14，没有中间档），不做字距调整。

## 禁忌

- 阴影、渐变、模糊
- 圆角 >2px
- 任何"打磨感"的微交互（缓动、缩放、弹性）

## 数值起点

- 底 `#FFFFFF` 或 `#F0EFEA`，墨 `#111111`
- 强调色：`#1A1AFF` / `#FF3B00` / `#00E05A` 三选一，面积可大
- 圆角 0
- 动效 0ms（状态切换瞬时）

## 适合

创意工作室、活动页、独立产品、需要"有态度"的品牌表达。

## 不适合

需要信任背书的金融医疗、需要长时间阅读的文档、B 端复杂表单（硬边框在高密度下会造成视觉噪音）、需要无障碍高可读性的场景（高饱和大面积色块常导致对比度问题）。
