# register: industrial（结构外露）

不隐藏构造。网格、边框、标尺、序号都摆在明面上。

## 标志手法

- **R1** 可见的分隔线（1px 实线，不透明或低不透明），把所有区块切开。区块之间不用留白暗示边界，用线明说。
- **R2** 等宽数字（`tabular-nums`）+ 左对齐标签 + 右对齐数值，形成"仪表"感。
- **R3** 编号、刻度、坐标轴、单位标注必须出现。它们不是装饰，是"这是工具不是广告"的信号。

## 禁忌

- 大圆角（>8px）与胶囊形控件
- 柔和渐变、玻璃拟态
- 大面积纯色块（应改用线框）

## 数值起点

- 底 `#F4F3EF` 或 `#14161A`（明暗皆可，但只有一个），线 `rgba(0,0,0,.14)`
- 强调色：单一高饱和（橙/黄绿），面积 <5%
- 圆角 0 / 2
- 字重 500 起，不用 300/400 做标题

## 适合

开发者工具、监控面板、硬件产品、B 端后台、需要"专业/精确"信号的场景。

## 不适合

消费类电商、健康/医疗（显得冷酷）、儿童产品、需要情感安抚的场景。
