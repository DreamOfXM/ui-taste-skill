# pattern: marketing-hero（营销首屏）

## 区块顺序

1. 主标题（≤12 字，说结果不说功能）
2. 副标题（≤2 行，说清怎么做、给谁）
3. 主 CTA + 次要 CTA（次要的视觉权重不超过主的 40%）
4. 一个"证据"元素：产品截图 / 数据 / 客户 logo / 一句带名字的评价（选一个）
5. 向下引导（可选，仅当页面确实有下一屏内容时）

## 每块职责

- **1 必须能被截图独立传播**。首屏是社交分享的主要对象，标题 + 副标题要能脱离页面成立。
- **4 只能有一个**。截图 + 数据 + logo + 评价全放上，等于什么都没有——每个都在削弱其他。
- **3 的主 CTA 只做一件事**。同时"免费试用"和"预约演示"会让用户停下来想"我该选哪个"，这是首屏最贵的成本。

## 常见塌陷点

- **标题是功能描述**："强大的数据分析平台" → 应改为结果："把三个月的报表压成一张图"。
- **渐变球/网格背景**：这是 2024–2026 年 AI 生成页面的典型签名，出现即暴露来源。要么不用，要么用得有物理依据（光从哪来）。
- **首屏高度写死 100vh**：小屏笔记本上会把 CTA 挤到折叠线以下。用 `min-height`。
- **三列 feature 图标区紧跟首屏**：这是模板默认结构。除非 brief 明确要求，否则跳过它，直接进入"证据"。

## 必须回答的问题

- 用户从哪个渠道来？（搜索来的要看关键词匹配，社群来的要看社交证明，销售发的要看可信度）
- 首屏在 375px 宽、667px 高时，主 CTA 是否仍在折叠线以上？
- 这一屏如果只剩一个元素，留哪个？

## 与其他 pattern 的组合

- `editorial`：标题巨大 + 单栏正文 + 无图，靠文字本身撑住
- `industrial`：首屏放产品真实界面截图（含数据），标题压小
- `brutalist`：单色块 + 超大标题，无副标题
